# møni – i18n-Keys der Identity (B5)

Neue Namespaces in `src/i18n/locales/{de,en}/`: `identity`, `rhythm`, `achievements`, `nudges` (insgesamt 469 Keys je Sprache, Plural-Paare als ein Key gezählt). Registriert in `src/i18n/index.ts`, typisiert über `deTranslation`. **UI-Agents verwenden diese Keys und legen keine eigenen an**; fehlt etwas, beim Lead melden.

## Regeln

- Aufruf: `t('identity.ring.roomLeft', { kcal })`. Kein Template-Literal in `t()` (typisierte Keys): für Listen (`achievements.<id>.*`, `rhythm.stage.name.<key>`, `identity.daySentence.<key>.<variante>`) ein `Record<Id, string>` aus literalen `t('…')`-Aufrufen bauen.
- Plural per i18next: Keys mit `_one` / `_other` werden mit `t('rhythm.counter', { count })` aufgerufen (Basis-Key ohne Suffix).
- Name immer klein: „møni“. Keine Emojis. Höchstens ein Gezeiten-Begriff (Pegel, Flut, Gezeitentafel, Springflut, Hochwassermarke) pro Screen; Settings-, Rechts- und Lösch-Texte ohne Markenbegriffe.
- Zahlen und Datum vorformatiert übergeben (Tausenderpunkt / Dezimal je Locale, Datum via `Intl`).
- Parität DE/EN (Keys, Platzhalter, keine Emojis, Schreibweise møni) prüft `src/i18n/locales.test.ts`.
- Bestehende Keys in `account`, `food`, `insights`, `workout`, `notifications` wurden nur im Text angepasst, nie umbenannt. Neue Tide-Begriffe dort: Pegel, Flut, Teller, Stammgerichte, Einheit.
