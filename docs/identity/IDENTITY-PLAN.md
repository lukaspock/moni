## 1. Die Marke in einem Satz

**møni ist der Lotse für deinen Tag: ein Pegel, in dem Essen und Training zusammenlaufen.** Tagline: „Dein Tag hat Gezeiten.“ / „Your day has tides.“

- Look: _Nachtschicht im Fjord_ – grün getönte Dunkelheit, warmes Papier, ein leuchtender Lime-Akzent.
- Zeichen: der **Schnitt-Ring (ø)** – Ring = Essen/Pegel, diagonaler Strich = Training/Bewegung.
- Ton: gelassen, klar, warm-trocken, ehrlich, körperfreundlich. Zahl vor Adjektiv, kein Shaming, keine Emojis im UI.

## 3. Design-Tokens (Kurzfassung, Quelle Doc 02/03)

- **Farbe**: Accent Lime/Forest · Bonus Ember `#FF8A3D`/`#C2410C` · Danger `#FF5C66`/`#C62F3A` · Macros Protein Violett `#A18BFF`, Carbs Honig `#FFCB3D`, Fett Cyan `#4CCBF2` (immer mit Buchstaben-Marker) · Foam (Feier-Lichtpunkte) · warme Neutrale (Dark `#0C0F0D`…, Light Papier `#F5F1E8`…). Ember und Honig nie im selben Chart.
- **Typo**: Bricolage Grotesque 600/700/800 (Display, Hero-Zahlen, tabular), SF Pro (Text).
- **Form**: Radien Hero 32 · Karte 24 · Input 16 · Pill voll, `borderCurve: 'continuous'`; Dark ohne Schatten (Flächenstufen + 1-pt-Innenlinie), Light warme Schatten; 4-pt-Grid, Gutter 20.
- **Motion**: Dauern 90/160/280/520/900 ms, Springs tap/settle/bouncy/heavy, Press-Skala, Exit = 0,65 × Eingang. Alles ReduceMotion-sicher.
- **Haptik**: zentraler Wrapper `src/lib/haptics.ts` (40 ms Mindestabstand, Prioritäten, Settings-Toggle, Default an). Nie Warnhaptik für „über Pegel“.

## 4. Umsetzungsplan (Wellen)

Dateibereiche sind pro Agent exklusiv. Agents committen nicht; der Lead reviewt und committet pro Welle (Conventional Commits). Jede Welle endet mit `npm run typecheck && npm run lint && npm test && npm run format:check`.

### Welle 0 – Fundament (sequenziell, blockiert alles Visuelle)

Pakete: `react-native-svg`, `expo-linear-gradient`, `expo-font`, `@expo-google-fonts/bricolage-grotesque` (bereits installiert).

- **F1 Theme & Native**: `theme.config.js` (neues Schema laut Doc 02), `tailwind.config.js` (neue Token), `src/theme/colors.ts` (`themeColor`, `useThemeHex`, neue Namen, Alt-Namen als Alias beibehalten), `plugins/withAccentColor.js` (Colorsets), `app.json`/Plugin-Liste, Font-Loading im Root-Layout (nur Font-Block, kein Auth-Gate anfassen), `src/theme/motion.ts`, `src/lib/haptics.ts` + `src/lib/motionPrefs.ts`. Danach `npx expo prebuild --platform ios --clean` und Simulator-Build; Alt-Tokens bleiben als Alias, damit nichts bricht.
- Abnahme: App startet im Simulator, Farben/Schrift aktiv, keine transparenten Flächen.

### Welle 1 – Bausteine (parallel, nach Welle 0)

- **B4 Domain** (`src/domain/*` neue Dateien + Tests): `rhythm`, `stage`, `achievements`, `rituals`, `weeklyReview`, `nudges`, `care`, `shareCard` laut Signaturen Doc 05 §2/§3, plus `src/features/rhythm/` Ledger (MMKV). Keine UI.

## 6. Risiken

- Prebuild/Dev-Build nötig (Colorsets, `react-native-svg`, Fonts). Owner muss neu auf dem iPhone installieren (Free-Team-Profil 7 Tage).
- Lime-Tint auf Liquid Glass: Kontrast im Simulator prüfen.
- Font-Familiennamen erst nach erstem Build verifizierbar.
- Ledger-Performance bei langer Historie: paginiert + inkrementell.
- i18n-Typ-Keys: viele neue Keys, `i18next.d.ts` muss konsistent bleiben.
- Notification-Änderung (Opt-in) ändert Sprint-2-Verhalten.
